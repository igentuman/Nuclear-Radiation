## Защита

Костюм химзащиты обеспечивает ослабление радиации по всем четырём каналам (рентген, альфа, бета,
нейтроны). Ношение большего количества элементов мультипликативно увеличивает защиту.

| Канал | Защита | Примечания |
|---|---|---|
| **Рентген / Гамма** | Да | Снижается за счёт плотности материала химзащиты |
| **Альфа** | Да | Почти полностью блокируется |
| **Бета** | Да | Значительно снижается |
| **Нейтроны** | Да | Частично снижается; комбинируйте с блочным экранированием для сильных нейтронных источников |

**Шлем** также обеспечивает **газовую защиту**, которая предотвращает:
- Вдыхание радиоактивных газовых облаков от мощных источников (>= 200 ГБк)
- Попадание воздушных загрязнителей из инвентаря в лёгкие

## Другая броня

Ванильные железная, золотая, кольчужная и незеритовая броня также имеют встроенные значения
радиационной защиты (ниже, чем у химзащиты). Проверяйте подсказки предметов, чтобы увидеть точные
проценты для каждого канала.

## Улучшение с помощью экранирования

Вы можете дополнительно улучшить броню химзащиты с помощью [улучшений экранирования](shielding.md) на
столе кузнеца. Применение плотного радиационного экранирования (DPS) к полному комплекту химзащиты
обеспечивает максимально возможную защиту брони в моде.

## Советы

- **Надевайте полный комплект** при работе с радиоактивными материалами. Даже несколько секунд рядом с
  мощным источником без защиты могут дать опасную дозу.
- **Всегда надевайте шлем** в зонах с радиоактивными газовыми облаками - это единственная часть,
  обеспечивающая газовую защиту.
- **Комбинируйте с лекарствами**: надевайте химзащиту для пассивной защиты и носите
  [лекарства](medicine.md) для экстренного лечения.
- **Проверяйте подсказки**: каждый элемент брони показывает процент защиты по каждому каналу.
